# Configuração do Servidor Bella Derme
# Arquivo: config.txt
# 
# INSTRUÇÕES DE USO:
# ==================
#
# OPÇÃO 1 - Script Python (Recomendado):
# python3 server.py
#
# OPÇÃO 2 - Script Bash:
# ./start_server.sh
#
# OPÇÃO 3 - Comando direto:
# python3 -m http.server 8000
#
# ACESSO:
# =======
# • No seu computador: http://localhost:8000
# • De outros dispositivos: http://[SEU_IP_LOCAL]:8000
#
# DESCOBRIR SEU IP LOCAL:
# =======================
# macOS: ifconfig | grep "inet "
# Windows: ipconfig
# Linux: hostname -I
#
# DISPOSITIVOS SUPORTADOS:
# ========================
# • Computadores (Mac, Windows, Linux)
# • Smartphones (iPhone, Android)
# • Tablets (iPad, Android)
# • Smart TVs com navegador
# • Qualquer dispositivo com navegador web
#
# PORTAS ALTERNATIVAS:
# ===================
# Se a porta 8000 estiver ocupada, use:
# python3 -m http.server 8001
# python3 -m http.server 8080
# python3 -m http.server 3000
#
# TROUBLESHOOTING:
# ===============
# • Erro "Address already in use": Use outra porta
# • Não consegue acessar de outros dispositivos: 
#   - Verifique se estão na mesma rede WiFi
#   - Desative firewall temporariamente
# • Site não carrega: Verifique se o index.html está na pasta
#
# PARAR O SERVIDOR:
# ================
# Pressione Ctrl+C no terminal
